# Saikou! v8.1.0 リリースノート

**リリース日**: 2026-02-23

## 🎉 新機能

### 1️⃣ プロフィール画像のズーム表示
- **自分のプロフィール画像**: タップしてフルスクリーン表示
- **フレンドのプロフィール画像**: タップしてフルスクリーン表示
- **モーダル**: 画面タップまたは✕ボタンで閉じる
- **用途**: 画像の詳細を確認、アバターを大きく見る

### 2️⃣ インタラクティブな画像クロップエディタ
- **画像選択後**: 自動的にクロップエディタが表示
- **ドラッグ操作**: クロップ枠を移動して切り取り範囲を調整
- **ピンチ操作**: 2本指でクロップ枠のサイズを調整
- **正方形クロップ**: 常に正方形（1:1）で切り取り
- **高品質**: 400×400px の JPEG 形式で保存（品質 95%）
- **iPhone Safari 完全対応**: タッチ操作に最適化

## 🛠️ 技術的な改善

### クロップエディタの実装
```javascript
- タッチイベント処理（touchstart, touchmove, touchend）
- ピンチジェスチャーでリアルタイムリサイズ
- ドラッグでクロップ枠を移動
- Canvas API で画像を切り取り
- Blob 形式で Supabase Storage にアップロード
```

### ズームモーダルの実装
```javascript
- フルスクリーンオーバーレイ（z-index: 60）
- 画像クリックで event.stopPropagation() で親イベント防止
- モーダル外クリックで閉じる
```

## 📱 使用方法

### プロフィール画像をアップロードする
1. プロフィール画面を開く
2. 📷 ボタンをタップ
3. 画像を選択
4. **クロップエディタが表示される**
5. ドラッグで切り取り範囲を調整
6. ピンチでサイズ調整
7. 「決定」ボタンをタップ
8. アップロード完了！

### プロフィール画像を拡大表示する
1. 自分またはフレンドのプロフィール画像をタップ
2. **フルスクリーンで表示される**
3. 画面タップまたは✕ボタンで閉じる
