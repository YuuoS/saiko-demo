## 💰 1. ゲームエコノミー大幅改善（F2Pゲームデザイン）

### 問題
- 旧システム: 月間コスト **¥950/ユーザー** → 持続不可能
- ログインだけで年間 **¥9,000** 付与 → インフレ

### 解決策
**F2Pゲームのベストプラクティス適用**:
- ✅ ログインだけでは少額
- ✅ 努力（デイリー達成）で稼ぐ

## 🔔 2. プッシュ通知基盤実装（App Store 準備）

### 実装内容

#### 21:00 デイリーリマインダー
- **タイミング**: 毎日 21:00 JST
- **内容**: 「今日のタスクを達成しましょう！」
- **動作**: ローカルスケジューリング（Service Worker）

#### フレンド達成通知（基盤のみ）
- **トリガー**: フレンドがタスク達成時
- **内容**: 「[フレンド名] さんが今日のタスクを達成しました！」
- **実装状況**: 関数準備完了（バックエンド連携は Phase 2）

### 技術的実装

#### Service Worker (sw.js)
```javascript
// プッシュ通知受信
self.addEventListener('push', (event) => {
  // 通知を表示
  event.waitUntil(
    self.registration.showNotification(title, options)
  );
});
```

#### フロントエンド (index.html)
```javascript
// 通知権限リクエスト
await Notification.requestPermission();

// 21:00 リマインダースケジュール
scheduleDailyReminder();

// フレンド通知（準備）
window.sendFriendNotification(friendName);
```

### ユーザーフロー

1. **初回アクセス**: 通知権限リクエスト
2. **許可後**: Service Worker 登録
3. **21:00**: 自動通知表示
4. **通知タップ**: アプリを開く
